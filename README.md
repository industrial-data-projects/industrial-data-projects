## 📂 Featured Projects

### 📦 [Supply Chain & Inventory Analysis](https://github.com/industrial-data-projects/supply-chain-inventory-analysis)

Inventory and stock analysis dashboard built with Python, Pandas, Plotly, and Jupyter. Transforms raw inventory data from Excel and operational sources into interactive KPI dashboards and automated HTML reports.

**Key Focus:** Inventory Performance · Stock Analysis · KPI Monitoring · Reporting Automation

### 🏭 [Weekly Maintenance Report](https://github.com/industrial-data-projects/weekly_maintenance_report)

Automates weekly SAP PM maintenance reporting with Python and Jupyter, reducing a reporting workflow from 2.5 hours of manual Excel work to approximately 2 minutes. Generates bilingual (FR/EN) HTML reports, PDFs, and Excel files with maintenance KPIs and performance indicators.

**Key Focus:** SAP PM · Maintenance Analytics · MTTR · Reporting Efficiency · Data Reliability
